HAND CRAFT E-COMMERCE SYSTEM REVIEW
Checked on: 2026-03-16

OVERVIEW
- This system is split into three parts:
  - backend: Node.js + Express + MongoDB API
  - frontend: Expo + React Native app
  - ai-service: Flask + TensorFlow image feature extraction service
- The core commerce flow already exists: auth, products, cart, wishlist, checkout, orders, admin, blogs, reviews, and AI image search support.
- Current diagnostics do not show editor errors in the frontend or backend folders.

RECENT CHANGES FOUND IN THE SYSTEM

1. Auth token persistence
- Frontend auth now restores the logged-in session from AsyncStorage.
- Auth state now includes loading protection so admin redirect does not fire too early.

2. Password reset email
- Backend now uses nodemailer with SMTP support.
- Reset token generation and reset email sending are implemented.
- There is a fallback behavior if SMTP is not configured.

3. Product reviews UI
- Product single page now has a reviews tab.
- Users can load reviews, submit reviews, and delete their own reviews.
- Star rating picker and rating summary are already added.

4. Blogs connected to API
- Blogs listing page now loads blogs from backend.
- Search, pagination, category filtering, featured blog, and blog detail by slug are connected.
- Blog comments are connected on the single blog page.

5. Deals page connected to API
- Deals page now loads product data from the products API.
- It uses sale price logic and real category filtering.

6. Best-sellers page connected to API
- Best-sellers page now loads ranked products from the products API.
- It shows top products and category-filtered product lists.

DOCS AND CONFIG ISSUES
- Frontend README is still the default Expo starter README and does not describe this project.
- Frontend API URL is hardcoded to localhost instead of using env configuration.
- Backend/AI-service integration uses localhost assumptions.
- SMTP configuration needs proper env values to send real password reset emails.
- AI service README does not fully describe all implemented endpoints.
- The project would benefit from .env.example files for backend, frontend, and ai-service.

MAIN RISKS STILL IN THE SYSTEM
- Contact and newsletter flows look unfinished at system level.
- Production config is not centralized enough yet.
- AI-related flows depend on a second service and need better failure messaging.
- Operational setup is incomplete: tests, containerization, env samples, and deployment guidance are limited.

SUMMARY OF WHAT IS DONE VS WHAT IS LEFT
- Done: auth persistence, password reset email wiring, product review UI, blogs API connection, deals API connection, best-sellers API connection.
- Still left: contact integration, newsletter integration, env/config cleanup, stronger backend validation/security, AI-service resilience improvements, documentation cleanup.
